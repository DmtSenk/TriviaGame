# Contributing to TriviaGame

Thanks for contributing.

## Development Guidelines

- Keep changes focused and small.
- Follow existing naming and structure conventions.
- Avoid unrelated refactors in feature/fix pull requests.
- Ensure no secrets or credentials are introduced.

## Local Validation

Before submitting:

1. Restore dependencies
2. Build the solution
3. Run any relevant tests (if added in the future)

Recommended commands:

```bash
dotnet restore /home/runner/work/TriviaGame/TriviaGame/TriviaGame.sln
dotnet build /home/runner/work/TriviaGame/TriviaGame/TriviaGame.sln
```

## Pull Request Expectations

- Describe what changed and why.
- Mention any user-facing behavior changes.
- Include screenshots for UI changes when applicable.
- Keep commits clear and descriptive.
